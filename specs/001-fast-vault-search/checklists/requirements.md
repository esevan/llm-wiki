# Requirements Checklist: Fast Vault Search

- [x] Search value is independent of Obsidian and model availability.
- [x] Paths, frontmatter, headings, tags, aliases, links, and content are retrieval signals.
- [x] Structural startup and structural search remain usable without an AI provider.
- [x] Independent semantic corpus search is specified separately from lexical retrieval.
- [x] Browser typography requires no runtime font-network request.
- [x] Indexing skips unchanged documents.
- [x] Result citations include path and source hash.
- [x] Reference-vault structural-index gate is automated.

# Task 계보와 Knowledge

[English](lineage-knowledge-layer.md) | **한국어**

Task 상세는 Capture 출처, 선택적으로 연결한 정확한 Problem 리비전, Work Log 근거·댓글·체크리스트·결정·완료 근거·연결을 함께 보존합니다. 이 결정적 기록은 Task 완료 후 비공개 Knowledge 초안을 만드는 원본이며 자동 발행되지 않습니다.

![작업 근거와 출처를 함께 보존하는 Task 상세](images/task-detail.png)

초안을 명시적으로 만들고 검토·수정한 뒤 별도로 발행합니다. 발행하면 영어 canonical Markdown을 Vault에 저장하고, 동시에 `Translations/ko/` 아래의 한국어 번역 작업을 자동으로 큐에 넣습니다. 초안 리비전과 콘텐츠 해시가 발행 원본을 식별합니다. 발행한 Vault 파일이 외부에서 바뀌면 해시 검사로 조용한 덮어쓰기를 막습니다. 재생성은 기록한 Task에서 초안을 갱신하며 Task의 비공개 기록을 지우지 않습니다.

이전 Solution 계보 탭, 추론 주장 교정 화면, 자동 완료 보고서는 보존한 레거시 동작·명세 기록입니다. 현재 Task 인터페이스가 제공한다고 약속하는 기능이 아닙니다. 현재 계약은 Task 중심의 [012 명세](../../specs/012-task-centered-workbench/spec.md)이며, [010 명세](../../specs/010-lineage-knowledge-layer/spec.md)는 Solution 시대의 역사적 설계로 남습니다.

[완료와 Knowledge](completion-writeback-archive.ko.md)와 [Task 중심 Workbench](conflict-gated-workflow.ko.md)를 참고하세요.

검토 탭은 새 비공개 초안을 수정하는 동안에도 앱에서 발행한 현재 버전을 보여 줍니다. 발행본과 초안 미리보기는 오픈소스 react-markdown 뷰어로 표, 링크, 코드 블록, 작업 목록을 표시합니다. FrontMatter는 읽기 화면에서 제외하고, 초안 입력란은 일반 굵기의 본문 글꼴을 사용합니다. 새로 생성하는 문서는 업무 맥락, 진행 과정, 판단, 결과와 검증을 설명하며, AI는 근거가 있는 새로운 지식과 나중에 참조할 가치를 정리합니다. 빈 섹션과 미기록 안내 문구는 생략합니다. 내부 ID, 리비전, 해시와 출처 계보는 발행 파일의 FrontMatter에서 관리합니다. 기존 발행 문서는 검토한 새 버전을 발행하기 전까지 그대로 보존합니다.

## 기록된 여정과 AI 해석

Task 상세는 기록된 여정을 그래프로 표시합니다. 넓은 패널에서는 이벤트가 3열을 지그재그로
이어 가고, 좁은 패널에서는 세로 1열로 바뀝니다. 옅은 화살표는 기록된 시간 순서만 보존하며
원인을 주장하지 않습니다. 실제 경과 시간과 관계없이 노드 사이 시각적 간격은 고정되며,
24시간 이상 간격이 있으면 날짜 간격을 찢어진 종이 모양으로 표시합니다. 출발점, 중요한
정제나 Task 변경, 결정, 완료, 여러 관계가 만나는 분기점은 서로
다른 모양이나 강조로 구분합니다. 노드를 선택하면 전체 활동 기록을 볼 수 있습니다.

AI는 짧은 로케일별 레이블과 나중 이벤트에서 이전 이벤트를 향하는 `supersedes`,
`derived_from`, `depends_on` 관계를 제안할 수 있습니다. 화면에서는 각각 **대체**(나중 선택이
이전 선택을 대신함), **파생**(나중 결과가 이전 근거에서 발전함), **선행 필요**(나중 단계가
이전 선행 조건에 의존함)로 표시합니다. 관계 종류와 방향이 유효하고 양쪽
이벤트에서 인용한 근거가 모두 확인될 때만 관계를 보존합니다. 레이블은 48자로 제한합니다.
이 관계는 해석으로 따로 표시하며, 기록된 이벤트나 시간 순서 간선을 바꾸지 않습니다.
provider를 사용할 수 없거나 결과가 유효하지 않으면 결정적 레이블과 추론 관계가 없는
그래프를 계속 사용할 수 있습니다.

현재는 추론한 관계를 사용자가 교정하는 UI가 없습니다. 사용자는 관계의 설명과 양쪽 끝점의
인용을 검토할 수 있으며, 원본 활동 기록이 계속 기준입니다.

## Knowledge 초안이 사용한 정확한 여정

앱에서 Knowledge 초안을 생성하면 선택한 로케일의 현재 여정을 먼저 만들거나 재사용합니다.
변경되지 않는 초안 계보는 그 정확한 스냅샷을
`lineage.journey = { sourceHash, journey, modelStatus, modelError }` 형태로 저장합니다. 자세한
형식은 [현재 데이터 모델](../../specs/012-task-centered-workbench/data-model.md)을 참고하세요.
초안 생성은 이 여정으로 결정의 변화, 대체된 선택, 파생 관계, 선행 조건을 설명하며 추론한
관계는 해석임을 밝힙니다. 비동기 생성 중 Task 근거, 완료 정보 또는 여정 입력이 바뀌면 새
근거 위에 오래된 결과를 저장하지
않고 거부합니다. 사용자나 MCP가 본문을 직접 제공한 초안은 제공된 원본 경계를 사용하며
여정 추론을 자동으로 실행하지 않습니다.

Details 화면은 현재 Task 여정을 보여 줍니다. Review 화면은 선택한 초안이 캡처한 여정을
보여 주므로, 이후 그래프를 새로 만들어도 기존 초안의 근거가 조용히 바뀌지 않습니다. 초안
스냅샷이 없으면 Review도 현재 여정을 표시합니다. 인터페이스 언어를 바꾸면 그래프 UI 문구와
날짜가 현지화됩니다. 새로 생성한 현재 그래프는 해당 로케일의 레이블을 가질 수 있지만,
변경되지 않는 초안은 생성 당시 캡처한 로케일과
레이블을 유지합니다. 언어 전환만으로 그 스냅샷을 다시 번역하지 않습니다.

로케일별 레이블을 만드는 실제 provider 경로는 UI 검증이 아직 필요합니다. 기존 시각 자료는
영어·한국어 UI 문구와 혼합된 긴 제목을 확인했으며, provider가 영어와 한국어 레이블을 각각
생성하는 경로를 검증한 것은 아닙니다.

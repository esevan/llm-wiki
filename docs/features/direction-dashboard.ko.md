# Compass

[English](direction-dashboard.md) | **한국어**

> **Understand the work, never score the worker.**

![활동을 사람 점수로 바꾸지 않고 방향을 기록하는 Compass](images/compass.png)

Compass는 목표, 근거 기반 Problem 중요도, 불변 마일스톤 이벤트, 방향 신호를 저장합니다. 이 신호는
업무와 목표의 관계를 설명할 뿐 생산성 점수나 직원 순위가 아닙니다.

제공자 장애 중에도 로컬 화면에서 기존 방향과 근거를 유지할 수 있습니다.

관련 Spec Kit: [004 — Direction Dashboard](../../specs/004-direction-dashboard/spec.md)

Compass는 방향과 완료 목록 탭을 제공합니다. 완료 목록에는 하위 작업을 포함한 전체 완료 Task가 완료 시각의 최신순으로 표시되며, 항목을 선택하면 상세를 열 수 있습니다. Workbench는 진행 중인 Task 옆 작은 목록에 최근 완료 5개만 표시하며, 대기 카드가 없는 카테고리는 숨깁니다.

최근 완료 패널은 높이 320px로 고정됩니다. 제목은 고정되고 목록만 세로로 스크롤되며, 가장 최근에 완료한 작업이 맨 위에 표시됩니다.

# 현재 인터페이스 안내

[English](visual-guide.md) | **한국어**

2026-09-26에 저장소 기준선 `75ebe57`을 대조했습니다. 이 안내는 Capture부터 Knowledge 발행까지
현재 애플리케이션 화면과 사용자가 내리는 결정을 따라갑니다. 현재 인터페이스를 검증한 새 캡처 묶음이
저장소에 아직 없으므로 이미지 대신 실제 메뉴와 동작을 중심으로 설명합니다.

기본 내비게이션은 **워크벤치**, **Vault 검색**, **나침반**, **AI 설정**으로 이동합니다. 워크벤치에서는
아이디어를 추적할 작업으로 만들고, 나머지 화면에서는 근거를 찾고 방향을 기록하며 AI 연결과 모델 경로를
설정합니다.

## 1. 아이디어를 Capture하거나 Task로 등록하기

워크벤치는 같은 내용을 **Capture**로 저장하거나 바로 **Task**로 등록하는 간결한 입력 영역으로
시작합니다. 이어서 진행 중인 Task와 최근 완료한 Task가 표시됩니다. 그 아래의 **Inbox**, **다듬는 중**,
**정제된 Task** 영역에는 나머지 작업이 정리됩니다. 현재 Task에 집중하려면 **진행 중인 작업에 Focus**로
입력 영역과 아래 영역을 숨길 수 있습니다.

Capture를 저장하면 텍스트와 이미지가 즉시 보존됩니다. 정확한 저장 원본을 읽기 좋은 제목과 본문으로
정리하는 백그라운드 작업 하나가 실행되는 동안에도 카드는 Inbox에 그대로 남습니다. 카드에서 정리 중,
완료, 확인 필요 상태를 볼 수 있습니다. 생성 내용은 원본을 대체하거나 Task를 만들거나 Capture를
이동하지 않습니다. Refinement에서 원본을 별도로 확인할 수 있고, 실패해도 원본을 잃지 않고 재시도합니다.

[Capture 자동 정리](capture-auto-distillation.ko.md)와
[Task 중심 Workbench](conflict-gated-workflow.ko.md)를 참고하세요.

## 2. 대화와 정확한 참조로 다듬기

맥락을 더 보완해야 할 때 **다듬기**를 선택합니다. 첫 구조화 초안과 선택적 참조 조사가 백그라운드에서
실행되는 동안에도 Chat을 계속 사용할 수 있습니다. 초안에는 제안된 배경, 목표, 범위, 범위 제외 사항,
제약, 완료 기준, 접근법과 가정이 저장됩니다. 근거가 부족한 내용은 가정으로 표시합니다.

Chat 입력창에서 `@`를 입력하면 로컬 문서와 절을 찾습니다. 전송한 멘션은 정확한 문서 버전과 절의
연결을 유지합니다. 참조 목록은 발견, 열람, 멘션, 실제 사용, 채택, 제외를 구분합니다. 출처를 찾았다는
이유만으로 채택한 근거가 되지는 않습니다. 정확한 출처 뷰어에서는 Task를 바꾸지 않고 열람한 출처로
돌아가거나 이전·다음 버전을 열 수 있습니다.

초안을 편집하거나 복원하면 변경 불가능한 새 버전이 추가됩니다. 새로운 백그라운드 결과는 저장하지 않은
편집을 덮어쓰지 못합니다. **Task에 적용**은 현재 초안, Task, 대화, 계층과 출처를 확인한 뒤 Task를
바꾸는 별도 동작입니다. 화면을 닫거나 대화를 이어가는 것만으로 제안이 적용되지는 않습니다.

[근거를 반영하는 작업 초안](reference-aware-workbench.ko.md)과
[Refinement Preview](refinement-preview-status.ko.md)를 참고하세요.

## 3. 네 개의 Task 탭에서 작업하기

Task를 열면 다음 네 개의 탭이 순서대로 표시됩니다.

- **작업**에는 체크리스트, 저장된 Work Log 근거, 댓글, 첨부 파일과 명시적인 결정이 있습니다.
  완료된 Codex Run에는 읽기 쉬운 **Run 결과 정리**가 추가될 수 있으며 원본 근거도 계속 열어볼 수
  있습니다. 제안, 결정, 시도, 관찰, 수행, 검증은 서로 다른 상태로 표시됩니다.
- **세션**에는 저장된 작업 대화가 있습니다. 메모는 로컬에만 저장되고, **Codex로 실행**은 별도 Run과
  연결된 Work Log 기록을 만드는 동작입니다. 실행만으로 Task를 완료하거나 Knowledge를
  발행하지 않습니다.
- **세부 정보**에서는 정식 Task 정의, 원본 Capture와 Task 연결을 확인하고 편집합니다. 저장하지 않은
  정의 변경은 Task를 떠날 때 보호됩니다.
- **검토**에는 근거에 묶인 Task 여정, **현재 결정과 근거**, 준비 상태, 충돌 검토, 완료 근거,
  Knowledge 검토가 모입니다. AI의 발견 내용은 조언으로 남고 완료는 사용자가 명시적으로 결정합니다.

Task 여정은 기록된 근거를 바탕으로 점진적으로 갱신됩니다. 명시적으로 저장한 결정은 현재, 대체됨,
철회됨, 미해결 상태가 될 수 있습니다. 일반적인 AI 문장은 채택한 결정이 되지 않습니다. 원본이 바뀌면
마지막 정상 정리 화면을 오래된 상태로 유지하고 백그라운드에서 갱신합니다.

[Task 작업 세션](task-work-sessions.ko.md), [Task 충돌 검토](conflict-resolution-workflow.ko.md),
[Task 계보와 Knowledge](lineage-knowledge-layer.ko.md)를 참고하세요.

## 4. 발행 전에 Knowledge 검토하기

Task를 완료한 뒤 **검토**에서 정확한 현재 Task, 완료 기록, 정리된 작업, 근거와 실제 사용한 참조를
바탕으로 비공개 Knowledge 초안을 생성할 수 있습니다. **최종 결과**는 글과 구분해 먼저 표시됩니다.
**다시 살펴볼 아이디어**는 최종 글과 분리된 접힌 영역에 남고, 각 아이디어가 미검증, 보류, 범위 밖,
기각 중 어느 상태인지 유지합니다.

생성, 편집, 복원할 때마다 변경 불가능한 비공개 버전이 추가됩니다. 버전 선택기는 다시 생성하지 않고
저장된 버전을 읽고 비교하며 복원합니다. 원본이 달라지면 버전을 지우지 않고 오래된 상태로 표시합니다.

발행은 별도의 아카이브 제안에서 시작합니다. **이 파일 그대로 발행**을 선택하기 전에 정확한 파일과
경로, 출처 링크, 선택한 idea 파일과 관리되는 색인 변경을 확인합니다. 검토한 파일이 저장되고 색인된
뒤에만 발행이 완료됩니다. 색인 대기, 충돌 또는 복구 필요 상태는 화면에서 확인하고 복구할 수 있습니다.

[근거에 묶인 Knowledge 초안](knowledge-distillation.ko.md),
[검토 후 지식 아카이빙](knowledge-archive.ko.md),
[완료와 Knowledge](completion-writeback-archive.ko.md)를 참고하세요.

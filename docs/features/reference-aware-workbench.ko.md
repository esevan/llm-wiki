# 근거를 반영하는 작업 초안

**한국어** | [English](reference-aware-workbench.md)

정제는 검색 계획, 관련 로컬 Vault 근거, 구조화된 최종 초안 순서로 작업 제안을
준비합니다. 필요한 검색은 유용한 초안을 저장하기 전에 끝납니다. 부족한 근거는
가정으로 표시하며 검색 불필요, 검색 결과 없음, 작업 실패를 구분합니다.
정식 Task는 사용자가 명시적으로 적용한 뒤에만 변경됩니다.

생성된 초안은 설명, 배경, 목표, 범위, 범위 제외 사항, 제약, 완료 기준, 초기 접근법,
가정을 저장합니다. 사용한 주장에는 정확한 문서 버전과 절이 연결됩니다.
문서를 찾았다는 이유만으로 사용하거나 채택한 것으로 기록하지 않습니다.
생성 중 출처, Task, 대화 또는 저장된 초안이 바뀌면 늦게 도착한 결과가 현재
초안을 교체하지 못합니다.

선택적 조사는 대화와 독립적으로 실행되며 무한히 재시도하지 않습니다.
근거를 중요, 보충, 참고로 구분합니다. 현재의 중요·보충 결과는 다음 답변에
한 번 전달할 수 있고 참고 근거는 참조 데이터에 남습니다. 새 대화가 시작되면
완료되지 않은 이전 조사는 오래된 맥락으로 처리됩니다.

네이티브 애플리케이션은 변경 불가능한 초안 버전의 조회, 비교, 편집, 복원을
지원합니다. 복원은 새 초안을 추가하며 Task 이력은 바꾸지 않습니다.
명시적 적용은 현재 초안, 내용 해시, Task 버전, 대화, 계층, 출처를 하나의
트랜잭션에서 확인합니다. 확인에 실패하면 사용자 작업을 보존합니다.
다듬기 화면을 열었을 때 초안이나 진행 중인 작업이 없으면 첫 초안을 자동으로
준비합니다. 대화를 계속하는 동안 저장된 초안과 백그라운드 결과를 갱신합니다.
편집은 시작한 버전과 내용 해시를 유지하므로 새 결과가 저장하지 않은 편집을
덮어쓰지 못합니다. 화면을 떠나기 전에 편집을 저장하거나 취소하고, 현재 초안을
확인한 뒤 Task에 적용하세요.

메시지 입력창에서 @를 입력하면 로컬 문서와 절을 검색합니다. 화살표 키와 Enter로
정확한 멘션을 삽입할 수 있으며 자동 전송되지 않습니다. 보내기 전에 텍스트와
멘션 연결을 저장하고 다듬기를 다시 열면 복원합니다. 전송한 멘션만 대화 맥락에
포함됩니다. 결과가 없어도 참조 검색을 계속할 수 있고 새 결과가 도착해도 직접
사용자가 새 참조를 확인하거나 필터·정렬을 바꾸기 전에는 읽던 순서를 유지합니다. 참조 확인은 입력창을 막지 않고 제한된
선택적 조사를 시작합니다. 색인에 반영된 파일 이동 뒤에도 정확한 출처를 열 수
있으며 이전 내용이 없으면 재시도 가능한 오류를 표시합니다.

[기능 명세](../../specs/019-reference-aware-workbench/spec.md)와
[네이티브 어댑터 계약](../../specs/019-reference-aware-workbench/contracts/application-api.md)을 참고하세요.

참조 뷰어는 뒤로·앞으로 이동할 때 문서 버전과 절의 정확한 연결을 유지합니다.
불러오기 실패 시 재시도할 수 있으며 닫으면 출처 버튼으로 포커스가 돌아갑니다.
버전 비교는 저장된 두 버전을 명시적으로 요청합니다. 이전 버전 복원과 Task 적용은
서로 다른 사용자 작업입니다.


참조는 정확한 문서 버전별로 절을 묶어 한 페이지에 문서 20개씩 보여 줍니다.
검색어, 상태, 근거 관점, 정보 유형, 기록된 사용 상태로 필터링할 수 있으며 결과가
없어도 필터는 유지됩니다. 새 문서와 절은 ‘새 참조 보기’로 확인하거나 필터·정렬을
바꿀 때 목록에 반영됩니다. 비동기 도착만으로 읽던 행의 순서를 바꾸지 않습니다.

검색 결과를 여러 개 선택한 뒤 ‘선택한 멘션 삽입’을 누르면 선택 순서대로 입력됩니다.
입력창에서 Enter 또는 Space를 누르면 현재 결과를 전송 없이 삽입합니다. 같은 제목도
출처 ID와 버전으로 구분합니다. Backspace/Delete는 연결된 토큰 전체를 제거하며,
토큰 내용을 편집하거나 일반 텍스트를 붙여 넣어도 출처 연결을 새로 만들지 않습니다.
초안은 가정의 저장된 상태와 근거를 따로 표시하며, 참조 필터에서도 열람·멘션·사용·
채택·제외 기록을 구별합니다.

실제 사용 기록은 Capture의 수락 또는 적용 결정으로 생성한 Task에 이어집니다.
원본 Capture가 같다는 이유로 다른 Task에 참조를 공유하지 않습니다. Knowledge는
정확한 문서 버전과 절을 유지하고, 사용 및 반증 기록을 해당 근거가 뒷받침한 저장된
문장과 함께 묶습니다. 열람, 멘션, 검색 발견만으로 게시 링크를 만들지 않습니다.
사용자가 제외한 출처는 다시 사용으로 표시하기 전까지 제외되며, 자동 생성이나
채택으로 제외를 취소하지 않습니다.

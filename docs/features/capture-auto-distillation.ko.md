# Capture 자동 정리

[English](capture-auto-distillation.md) | **한국어**

새 Capture를 저장하면 텍스트와 이미지가 즉시 커밋됩니다. 그다음 LLM Wiki가 정확히 그 저장 원본에
대해 하나의 지속 가능한 백그라운드 정리 작업을 시작합니다. 텍스트 전용, 이미지 전용, 혼합 Capture가
같은 경로를 사용합니다. 기존 Capture는 바꾸거나 자동 처리하지 않습니다.

Inbox 카드는 같은 Capture로 같은 위치에 남습니다. 처리 중에는 조용한 진행 상태를 표시합니다. 현재
원본에 근거한 결과가 도착하면 짧은 콘텐츠 전환으로 읽기 좋은 제목과 본문을 바꿉니다. 이 전환은 카드
위치를 옮기거나 포커스와 입력을 초기화하지 않으며 workflow 상태 변경을 뜻하지 않습니다. 움직임 줄이기
설정에서는 애니메이션을 생략합니다.

## 원본과 생성 콘텐츠

최초 텍스트와 제출한 모든 이미지는 Refinement에서 별도로 확인할 수 있습니다. 생성 콘텐츠는 자체
리비전과 job provenance를 가집니다. 원본을 대체하거나 Task·Problem을 만들거나 사용자에게 보이는
버전 수를 늘리지 않으며 Capture를 Inbox 밖으로 옮기지 않습니다.

Refinement를 여는 동작은 기존 작업을 읽기만 합니다. 최초 정리 job을 다시 만들지 않습니다. 정리가
대기 중이거나 실행 중이어도 Chat 입력을 계속 사용할 수 있습니다. Chat 메시지가 현재 맥락을 갱신하면,
같은 최초 logical operation 아래에서 최신 맥락을 대표하는 후속 시도 하나를 사용합니다.

## 최신성, 실패, 재시도

생성 콘텐츠는 원본과 현재성 토큰이 모두 일치할 때만 적용합니다. 직접 편집한 내용이 항상 우선합니다.
유용한 이전 결과가 나중에 도착하면 현재 Capture를 덮어쓰지 않고 검토 가능한 이전 제안으로 남길 수
있습니다.

실패는 재시작 후에도 안전한 메시지와 함께 표시됩니다. 재시도는 등록된 원래 prompt와 정확한 원본
리비전을 유지하며, 같은 시도가 실행 중이면 반복 동작을 하나로 합칩니다.

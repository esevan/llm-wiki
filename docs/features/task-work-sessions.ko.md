# Task 작업 세션

**한국어** | [English](task-work-sessions.md)

Task 세부 정보의 세션 탭은 집중해서 진행한 내용을 Task의 정식 정의와 Work Log에서 분리해 보존합니다. Task를 여는 것만으로 세션이 생기지 않습니다. 필요할 때 **새 세션**을 선택하고, 이후 저장된 세션을 다시 선택해 이어갈 수 있습니다.

각 세션은 대화 형태의 사용자 메모, 메모별 최대 10MB의 선택적 파일 하나, 세션 제목과 실행 설정을 저장합니다. 붙여 넣은 이미지는 저장 전에 미리 보이며, 저장된 이미지는 다시 볼 수 있고 모든 첨부 파일을 다운로드할 수 있습니다. 저장에 실패하면 메모와 첨부를 입력창에 유지해 다시 시도할 수 있습니다. 저장된 기록은 앱을 다시 시작해도 복원됩니다. 저장하지 않은 초안은 Task 세부 정보를 열어 둔 동안 유지되지만 앱을 다시 시작하면 복원되지 않습니다.

맥락 열은 현재 Task 내용과 기존 참조를 읽습니다. Task 사본을 따로 저장하지 않으며 다른 Task의 세션을 포함하지 않습니다.

제공자, 모델, 승인 검토자, 프로젝트 폴더 경로는 세션마다 저장됩니다. **대화 준비**는 정확한 세션을 Codex에 연결하고 실제 설정을 확인하지만 작업을 시작하거나 실행 기록을 만들지는 않습니다. 이후 **설정 확인**으로 결과를 다시 확인할 수 있습니다. **메모 저장**은 메모와 첨부만 기록합니다. **Codex로 실행**은 별도의 명시 동작으로, Codex가 시작되기 전에 변경 불가능한 실행 기록 하나와 연결된 Work Log 행 하나를 저장합니다. 이후 실행은 이전 대화를 다시 보내지 않고 같은 세션의 정확한 Codex 대화를 이어갑니다.

실행 타임라인은 안전한 제공자 상태, 완료된 관찰 근거, Codex 최종 보고를 서로 구분해 표시합니다. Codex가 돌려준 실제 모델, 정규화된 폴더, 승인 정책, 검토자, 샌드박스도 표시합니다. 중지는 인터럽트를 요청할 뿐이며 최종 제공자 상태가 완료·실패·취소를 결정합니다. 중단되었거나 결과가 불확실하면 작업이 이미 수행되었을 수 있으므로 새 실행 전에 저장된 근거를 확인해야 합니다. **지시 다시 사용**은 입력창이 비어 있을 때 이전 지시를 불러옵니다. 이후 **Codex로 실행**을 눌러야 새 시도가 생성되며 다른 초안을 덮어쓰지 않습니다.

정식 승인은 Codex가 보낸 실제 선택지만 제공합니다. 구조화된 질문은 비밀값이 아닌 답변을 선택하거나 입력한 뒤 한 번 명시적으로 제출해야 합니다. 오래된 요청은 비활성화되고 실패한 답변은 다시 시도할 수 있게 유지됩니다. Work Log 실행 블록은 정확한 세션과 실행으로 돌아갑니다. Codex 실행은 Task를 완료하거나 Problem을 해결하거나 Knowledge를 발행하지 않습니다. 전체 경계는 [기능 명세](../../specs/014-task-codex-execution/spec.md)를 참고하세요.

이번 기능에서 첨부는 메모에 저장되며 Codex로 전달되지 않습니다. **사용자에게 묻기**은 승인을 사용자에게 전달합니다. **자동 검토**는 명시적으로 새로 선택해야 하며 Codex의 기존 승인 정책과 샌드박스를 유지합니다. 이전에 저장된 자동 승인 선호만으로 권한을 부여하지 않습니다.

세션을 사용해도 Task를 완료·재개하지 않습니다. 메모 저장은 AI를 호출하지 않습니다.

# Bundled embedding model

LLM Wiki bundles the quantized ONNX distribution of
`sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2` from
`Qdrant/paraphrase-multilingual-MiniLM-L12-v2-onnx-Q` at the immutable
revision recorded in `manifest.json`.

The model is licensed under Apache-2.0. Its model card and license metadata are
available at:

- https://huggingface.co/Qdrant/paraphrase-multilingual-MiniLM-L12-v2-onnx-Q
- https://huggingface.co/sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2

Model inference runs locally. Model files are packaged inside the desktop
application and are not downloaded when the application starts.
